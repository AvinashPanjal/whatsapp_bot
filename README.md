# 🤖 WhatsApp Gemini Bot

A WhatsApp bot powered by Google's **Gemini 2.5 Flash** model and **whatsapp-web.js**. 

Features an express server dashboard to display the QR code for scanning and monitor health status, along with Docker configuration ready for deployment on **Render** and **Railway**.

---

## 🚀 Features

- **WhatsApp Web Integration**: Uses `whatsapp-web.js` to log in via QR code scanning.
- **Gemini AI**: Uses `@google/genai` (Gemini 2.5 Flash model) to generate responses.
- **Web QR Code Viewer**: Open `http://localhost:3000` to view and scan the QR code directly from your browser.
- **Terminal QR Code**: Renders a small ASCII QR code directly in the terminal logs.
- **Docker-Ready**: Includes a optimized `Dockerfile` with Chromium preinstalled for cloud deployments.

---

## 🛠 Local Setup & Running

### 1. Requirements
- Node.js 18+ installed on your computer.
- A WhatsApp account on your smartphone.
- A Gemini API key (already included in `.env`).

### 2. Installation
Open a terminal in this directory:
```bash
npm install
```

### 3. Start the Bot
```bash
npm start
```

### 4. Link your WhatsApp Account
1. Look at the terminal output or navigate to `http://localhost:3000` in your web browser.
2. You will see a QR code generated.
3. Open **WhatsApp** on your phone:
   - Tap **Settings** (or 3 dots menu) > **Linked Devices** > **Link a Device**.
4. Scan the QR code displayed on the screen.
5. Once scanned, the status changes to `Ready & Connected`. Any incoming WhatsApp message will receive a response generated by Gemini!

## ☁️ Hosting on Railway (Recommended)

Railway makes Docker deployments straightforward and provides generous resources.

1. **Push to GitHub**:
   - Initialize a git repository and push this folder to GitHub.
   ```bash
   git init
   git add .
   git commit -m "Initial commit for WhatsApp Gemini Bot"
   ```
2. **Deploy on Railway**:
   - Go to [Railway.app](https://railway.app) and sign in.
   - Click **New Project** > **Deploy from GitHub repo**.
   - Select your `whatsapp-gemini-bot` repository.
   - Railway will automatically detect the `Dockerfile` and build it.
3. **Set Environment Variables**:
   - Go to the **Variables** tab in Railway.
   - Add:
     - `GEMINI_API_KEY`: `YOUR_GEMINI_API_KEY`
4. **Scan QR Code**:
   - Generate a public domain under **Settings > Networking > Generate Domain**.
   - Open that domain in your browser to view the QR code and scan it with WhatsApp. Alternatively, view the QR code in Railway's deployment logs!

## ☁️ Hosting on Render

Render supports Docker Web Services.

1. **Push to GitHub** (same as above).
2. **Create New Web Service on Render**:
   - Go to [Render Dashboard](https://dashboard.render.com).
   - Click **New +** > **Web Service**.
   - Connect your GitHub repository.
   - Select **Docker** as the Runtime.
3. **Add Environment Variables**:
   - In Render, add:
     - `GEMINI_API_KEY`: `YOUR_GEMINI_API_KEY`
4. **Deploy**:
   - Click **Create Web Service**.
   - Once deployed, visit your Render app URL (`https://your-app.onrender.com`) to view the QR code and scan it.

## ⚙️ Configuration (.env)

| Variable | Description | Default |
|---|---|---|
| `GEMINI_API_KEY` | Google Gemini API Key | *(Set in .env)* |
| `PORT` | Server & Dashboard Port | `3000` |
| `BOT_PREFIX` | Prefix required to trigger bot (e.g. `!ai`). Leave blank for all DMs. | `""` |
| `ALLOW_GROUPS` | Set `true` to respond in WhatsApp group chats without prefix. | `false` |
| `GEMINI_MODEL` | Gemini AI Model | `gemini-2.5-flash` |
| `SYSTEM_INSTRUCTION` | System prompt instruction for the AI assistant | *(Friendly Assistant)* |
